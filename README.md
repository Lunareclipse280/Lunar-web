# Lunar-web
## Personal Portfolio  
A responsive, animated personal portfolio website designed to showcase full-stack development projects, technical expertise, and professional branding.

## Features
Dynamic Animations: Features custom name-cascade entry effects and staggered visual reveals.

Fully Responsive: Optimized layouts built with modern CSS (Flexbox and Grid) to look sharp on any device, from mobile screens to desktop monitors.

Project Showcase: Highlights core interactive web applications, including a real-time Budget Tracker, a keyword-filtering Search Engine, and an API-driven Weather App.

SEO Optimized: Structured markup and descriptive metadata designed for clean search indexing and professional visibility.

 ## Tech Stack
Markup & Styling: HTML5, CSS3 (Advanced Animations, Flexbox, CSS Grid)

Logic & Interactivity: JavaScript (ES6+, DOM Manipulation, Asynchronous API Integration)

Version Control: Git & GitHub
